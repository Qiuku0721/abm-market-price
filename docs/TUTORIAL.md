# 使用教程（新手向）

本工具分两部分：**手机上的 App**（自动看游戏市场、认价格、点屏幕）和**电脑上的程序**（收数据、存起来、画图表）。手机 App 认到的价格会**通过 USB 数据线（推荐，更稳定）或 Wi-Fi** 发给电脑。

> ⚠️ 先说风险：让 App 自动点击游戏界面，有被封号的概率。请用小号、控制频率、自己斟酌。

---

## 你需要准备

| 东西 | 说明 |
|---|---|
| 一台电脑（Windows） | 装 Python 3.10+（见 `SETUP.md`），跑「电脑端程序」 |
| 一部安卓手机（Android 8.0+） | 跑「手机 App」 |
| USB 数据线（推荐）或同一 Wi-Fi | 传输数据（USB 模式需开启 USB 调试） |
| Android Studio | 用来把 App 源码编译成安装包（`.apk`） |
| 游戏账号 | 你自己承担风险 |

---

## 第一步：启动电脑端程序

```bash
cd pc
scripts\start.bat        # Windows：第一次会自动建环境、装依赖
```

看到 `Uvicorn running on http://0.0.0.0:8600` 就成功了。

浏览器打开 `http://127.0.0.1:8600`，能看到统计页面（现在还是空的）。

**用 USB 线连手机（推荐，最稳定）**：手机插上数据线 → 打开「开发者选项 → USB 调试」并允许本电脑授权 → 双击 `pc\scripts\usb-link.bat`，看到「连接成功」即可。此时 App 里地址填 `http://127.0.0.1:8600`（走数据线，不用 Wi-Fi）。

> 不用 USB、走 Wi-Fi 时：`cmd` 里输入 `ipconfig` 记下 IPv4 地址（如 `192.168.1.100`），App 里填 `http://192.168.1.100:8600`，且手机、电脑须在同一 Wi-Fi。

> 手动方式：`python -m venv .venv` → `.venv\Scripts\activate` → `pip install -r requirements.txt` → `python server.py`（都要在 `pc/` 目录里做）。

---

## 第二步：编译手机 App，找到 APK

**方式 A（推荐）：用 Android Studio**

1. Android Studio 打开本项目的 `android` 文件夹（菜单 File → Open）。
2. 等右下角 Gradle 同步完成（第一次要下载，耐心等）。
3. 顶部菜单 **Build → Build Bundle(s) / APK(s) → Build APK(s)**。
4. 右下角弹出提示，点 **locate / 在资源管理器中显示**。

**方式 B：命令行**

```bash
cd android
gradlew.bat assembleDebug
```

**APK 在哪里？** 编译完成后在：

```
android\app\build\outputs\apk\debug\app-debug.apk
```

把这个文件发到手机（微信/QQ/数据线都行）或直接用 USB 数据线安装：

```bash
adb install -r android\app\build\outputs\apk\debug\app-debug.apk
```

> 手机装第三方 App 若被拦截，去「设置 → 安全 → 允许安装未知来源应用」打开对应入口的开关。

---

## 第三步：开启手机上的两个权限

1. **无障碍服务**（App 靠它来点击屏幕）
   - 手机「设置 → 无障碍 → 已下载的应用」找到 **ABM Collector 手势服务**，打开。
2. **通知权限**（Android 13+ 首次打开 App 时会弹窗，选允许，用于显示运行状态）。

这两个缺一个 App 都无法工作，App 界面也会提示。

---

## 第四步：打开游戏，开始采集

1. 打开 **ABM 价格记录器** App。
2. 填「电脑端地址」：USB 模式填 `http://127.0.0.1:8600`（默认值即是）；Wi-Fi 模式填电脑局域网 IP。
3. 填「采集周期」：单位是**秒**，默认 `60`（即 60 秒一轮）。想更快可以填 `10~30`（最短 5；越快风险越高）。
4. 「子弹清单」：每行写一个子弹名，例如：
   ```
   M80 5.56x45
   M855 5.56x45
   ```
5. （可选）「导航点击」：如果打开 App 时你不在子弹列表页，而是停在游戏大厅/市场入口，需要 App 每轮先点几下进到列表。填法：**每行两个 0~1 的数字（宽,高）**，例如先点底部「市场」入口在屏幕 `0.5,0.92`、再点「子弹」分类在 `0.5,0.45`，就填两行 `0.5,0.92` 和 `0.5,0.45`。坐标要自己在游戏里目测，点错位置 App 日志会有提示。
6. 点「**保存清单**」，再点「**开始采集**」。
6. 第一次会弹「屏幕录制」授权——**必须点允许**。
7. 把游戏切到**市场列表页**（能看到子弹名称和价格的列表），App 会自己滚动屏幕找清单里的子弹。

> 期间**不要切走**游戏画面。想让它先跑几轮观察，可以盯 App 界面下方的「运行日志」。

---

## 第五步：在电脑上看结果

浏览器回到 `http://127.0.0.1:8600`，可以看到：

- **最新价格**：每个子弹现在多少钱、比上一次涨了还是跌了
- **价格走势**：点某个子弹名，选 1小时 / 1天 / 7天 / 30天 看曲线
- **历史明细**：所有记录，带「查看」链接的是 App 当时截的图，用来**人工核对 App 有没有认错价格**
- **子弹清单**：可以增删
- **导出 CSV / Excel**：把数据下载成表格文件

手机端到电脑端数据大概 1~2 分钟内可见（等一轮采集 + 上报）。

## 常见问题

| 现象 | 怎么办 |
|---|---|
| 电脑端页面打不开 | 确认 `start.bat` 窗口还开着、没报错；浏览器用 `http://127.0.0.1:8600` |
| App 日志写「无障碍服务未连接」 | 去系统设置开启 ABM Collector 手势服务，再点「停止」→「开始采集」 |
| 点了开始没反应/黑屏 | 重新点「开始采集」，把「屏幕录制」授权再允许一次（安卓系统每次都要确认） |
| 页面一直没有新数据 | ① USB 模式是否跑过 `usb-link.bat`（拔线/重启后要重跑）② App 地址是否为 `http://127.0.0.1:8600` ③ 电脑端 `start.bat` 是否在运行 |
| 总显示「未找到 XXX」 | 该子弹没在当前市场列表页出现，或名字被换行显示了；看看游戏里市场列表是否要翻很多页 |
| 价格认错了 | 看明细里的「查看」截图，对照一下；识别不准可多等几轮，界面截图差异大时属于正常现象 |
| 被封号风险 | 用不心疼的小号，把采集周期调大（比如 300 秒以上） |
